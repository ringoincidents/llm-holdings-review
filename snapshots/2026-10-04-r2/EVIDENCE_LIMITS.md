# Evidence Limits

This public snapshot is intentionally incomplete.

## What this round can support

The included files can be used to inspect:

- selected authority and Lab routing behavior;
- memory trust boundaries;
- Record Writer behavior;
- runtime operational controls and telemetry structures;
- selected production E2E smoke-test logic;
- selected federation/reconciliation tests;
- QuanTrade public-facing workspace structure.

## What this round cannot fully prove

It does **not** prove:

- live Railway availability;
- real production cost;
- historical uptime;
- all stuck-work recovery paths;
- real provider outage behavior;
- private deployment configuration;
- complete security posture;
- every private memory-scope path;
- complete TASKS backlog state.

Those claims require additional runtime/deployment evidence that is intentionally not public by default.

Therefore external reviewers should mark production-operability conclusions `PARTIAL` or `UNVERIFIED` unless supported by the included evidence.

A reviewer may request the minimum additional sanitized evidence through an Issue.
