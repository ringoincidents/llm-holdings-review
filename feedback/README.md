# Feedback Intake

Public feedback arrives through Issues and Pull Requests.

Maintainers/AI agents should process material items using `MAINTAINER_PROTOCOL.md` and append a durable disposition to `REVIEW_DECISIONS.md`.

## Why keep a disposition log?

External review is useful only if the project can later answer:

- what was suggested;
- what evidence supported it;
- whether it was accepted;
- whether it changed upstream;
- why it was rejected;
- whether later evidence superseded the decision.

This folder provides that memory without treating external input as automatic authority.
