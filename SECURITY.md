# Security Policy for the Public Review Hub

This repository is public.

Do **not** disclose:

- credentials or API keys;
- authentication tokens;
- private deployment URLs;
- personal/client financial data;
- raw private organizational memory;
- exploitable production details.

If you believe you found a security issue, do not open a public Issue containing sensitive details.

Contact the repository owner privately through an appropriate GitHub channel and provide only the minimum information needed to reproduce the concern.

Public snapshot content should be considered review material, not a complete production-security disclosure.
